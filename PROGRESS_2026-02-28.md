### 5. Dark Mode (Phase 7)

**File:** `lib/app.dart`

```dart
// Sebelum
themeMode: ThemeMode.light,
materialThemeBuilder: (context, theme) => AppTheme.materialLightTheme(),

// Sesudah
themeMode: ThemeMode.system,  // otomatis ikut device
materialThemeBuilder: (context, theme) {
  final isDark = MediaQuery.platformBrightnessOf(context) == Brightness.dark;
  return isDark ? AppTheme.materialDarkTheme() : AppTheme.materialLightTheme();
},
```

`AppTheme.darkTheme()` (ShadCN) dan `AppTheme.materialDarkTheme()` (Material 3) sudah tersedia sebelumnya — hanya perlu diaktifkan.
